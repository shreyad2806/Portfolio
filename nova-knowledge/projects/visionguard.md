# VisionGuard

**One-liner:** A machine-learning image-quality assessment system.

**Stack:** Python, Scikit-learn, RandomForest, FastAPI, Computer Vision.
**GitHub:** https://github.com/shreyad2806/Vision-Guard

It uses a RandomForest regression model and a FastAPI backend to evaluate image-quality metrics; the model is exposed end to end through a FastAPI service.
